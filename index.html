LLS Menu API

The architecture. A shared REST API separates navigation data from the websites that consume it. The project brings together Node.js and Express, MySQL with Prisma, and React, with Docker and AWS Lightsail supporting delivery.

My contribution. I led the development of a shared navigation platform, collaborating with another developer on system architecture, API design, administrative workflows, and deployment. The project replaced repetitive site-by-site updates with a centralized approach to navigation management.
